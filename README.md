# 2026 활동지원사 송년행사 럭키드로우 웹앱

2026년 12월 4일(금) 송년행사 2부 경품 추첨을 위해 제작된 **디스코드 감성의 밝고 경쾌한 입체형 PC 및 빔프로젝터 전용 웹 추첨 도구**입니다.
인터넷 연결이 불안정하거나 끊겨도 100% 정상 작동하며, 별도 설치 없이 브라우저에서 바로 실행할 수 있습니다.

---

## 🚀 빠른 실행 방법
1. 폴더 내 **`실행하기.bat`** 또는 **`index.html`** 파일을 더블 클릭합니다.
2. 기본 웹 브라우저(Chrome, Edge, Whale 등)에서 즉시 실행됩니다.
3. 무대 빔프로젝터에 연결 후 우측 상단의 **[⛶ 전체 화면]** 버튼(또는 F11)을 눌러 행사 모드로 전환합니다.

---

## ✨ 핵심 개선 및 구현 사항

### 1. 디스코드 테마의 밝고 경쾌한 비주얼 & 입체감 (3D Tactile Design)
- 딥 인디고 & 블러플(#5865f2), 스프링 그린(#57f287), 네온 사이언(#00b0f4) 컬러가 어우러진 활기찬 축제 분위기.
- 실제 버튼을 누르는 듯한 **3D 입체 푸시 버튼** 및 글래스모피즘 베벨 섀도우 적용.
- 헤더의 테마 버튼으로 언제든 **[디스코드 테마]**와 **[클래식 골드]** 간 전환 가능.

### 2. 고화질 아케이드 슬롯머신 & 가독성 대폭 향상
- **시작 전 `?` 및 붉은색 센터 라인 제거**: 요청에 따라 시작 전 불필요한 물음표 기호와 중앙의 붉은 가로선을 완전히 제거하여, 깨끗하고 깊이감 있는 3D 릴 화면에서 쾌적하게 대기합니다.
- 3D 아케이드 캐비닛 프레임, 실린더 유리 반사광, 굵고 선명한 스탬프 폰트로 빔프로젝터 원거리에서도 탁월한 가독성 보장.
- 스릴 넘치는 릴별 순차 정지(Staggered Stop) 및 스프링 바운스 연출.

### 3. 신나는 경마 레이스 추첨 (10두 팩 레이싱 & 2.5D 입체 트랙)
- **부드러운 연속 질주 & 엎치락뒤치락 추월 연출**:
  - 끊김 없이 패럴랙스 잔디 트랙이 뒤로 흐르며, **10마리의 귀여운 경주마와 기수들이 나란히 달리며 엎치락뒤치락 선두를 다투는 박진감 넘치는 라이브 레이스**를 구현했습니다.
  - 4박자 갤럽 다리 관절 모션과 리드미컬한 몸체 바운스로 뚝뚝 끊김 없이 매끄럽게 질주합니다.
- **2.5D 원근감 & 입체 레이아웃**:
  - 안쪽 레인은 원근감으로 아담하고 은은하게, 앞쪽 레인은 큼직하고 또렷하게 배치하여 깊이 있는 입체감을 부여했습니다.
  - 흙먼지와 잔디 파편이 튀며, 결승선(FINISH)과 거리 표지판(200m, 100m)이 스크롤되어 긴장감을 극대화합니다.
- **나팔 소리와 말발굽 효과음**: 출발 시 경마 트럼펫(Bugle Call)과 함께 전력질주 말발굽 소리(Clip-Clop)가 재생됩니다.

### 4. 부재자 1명 단독 재추첨 & 대형 화면 발표
- 부재자가 발생했을 때, 해당 당첨자 카드의 **[부재 재추첨]** 버튼을 누르면:
  1. 부재 번호만 취소되고 즉시 **그 1명만을 위한 단독 재추첨 연출(슬롯 또는 경마 질주)**이 무대 전체 화면에서 펼쳐집니다.
  2. 추첨 완료 시 **"기존: OO번 (부재) ➡️ 새로운 당첨자: [ XX번 ]"** 형태로 초대형 결과 발표 화면이 빔프로젝터에 시원하게 공개됩니다.
  3. 발표 후 **[📋 전체 당첨 목록으로 복귀]** 버튼을 누르면 기존 정상 당첨자들과 합쳐진 전체 목록으로 깔끔하게 복귀합니다.
- 기본값: `1 ~ 70` 번 (원하는 범위로 자유롭게 변경 가능)
- 중복 당첨 영구 방지 (이미 당첨된 번호는 이후 추첨에서 자동 제외)
- 부재자 발생 시 안전 복구가 가능한 **[부재자 재추첨]** 기능 제공.

### 5. 100% 무중단 Web Audio API 사운드 시스템
- 외부 음원 파일 의존 없이 웹 표준 신디사이저로 생성 (BGM, 회전 긴장감 SFX, 당첨 팡파르).
- 상단 헤더에서 1클릭 음소거 및 상세 음량 조절 가능.

### 6. 전체 당첨 현황판 & 참가 번호 빠른 검색
- 상단 **[🏆 전체 당첨 현황판]** 탭에서 경품별, 회차별 당첨 번호 열람 및 "내 번호 검색"으로 실시간 당첨 확인.

## 📁 파일 구조
- `index.html`: 메인 웹 애플리케이션 진입점
- `styles.css`: 블랙&골드 및 디스코드 테마, 빔프로젝터 고대비 UI 스타일
- `app.js`: 참가자 번호 풀 관리, 중복 방지, 경품 관리, 추첨 컨트롤러
- `audio.js`: Web Audio API 기반 오프라인 사운드 엔진 (BGM/효과음/팡파르)
- `animations.js`: 골드 배경 파티클, 3D 럭키볼 물리 시뮬레이션, 컨페티 폭죽
- `실행하기.bat`: 원클릭 실행 배치 파일
